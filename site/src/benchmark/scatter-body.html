每任务 token、花费与缓存命中率

本仓库、官方 Claude Code 2.1.319、Codex CLI 0.167.0、opencode 1.19.5、pi 1.5.0、oh-my-pi 18.18.0、dsh 0.2.2-rc.1 跑同一批真实任务（2026-11-07）。越靠左上越好：用更少的 token（或花费），拿到更高的缓存命中。上方按钮可把横轴切换为 token 或 API 等价花费（美元）。颜色 = CLI，形状 = 账号类型（实心圆 Claude 订阅、菱形 ChatGPT 订阅、空心圆 Claude API key）。把鼠标移到点上（手机上点一下）查看明细，点图例可隐藏。

命中率 = 缓存读 ÷（未缓存输入 + 缓存读 + 缓存写），按 token 加权。模型：Claude 订阅与 Claude API key 都用 claude-sonnet-5-5，ChatGPT 订阅用 gpt-6.1-sol；effort 用各 CLI 默认值（见表格）。花费按公开 API 价换算（美元 / 百万 token）：gpt-6.1-sol 输入 2、缓存读 0.10、输出 10；claude-sonnet-5-5 输入 2、缓存读 0.20、5 分钟缓存写 2.50、1 小时缓存写 4、输出 10。本仓库与官方写 1 小时缓存，其他 CLI 写 5 分钟缓存。ChatGPT 订阅与 Claude 订阅本身是包月，实际不按此计费，这里换算只为横向比较。两种模型价格不同，跨模型只比较相对位置。pi 与 opencode 的 Claude 侧用 API key 在另一时段运行。官方 2.1.319 在 -p 下没有真正组成团队（带名字的 Agent 变成后台 subagent），标 * 的点仅作参考。
