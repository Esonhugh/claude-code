$ claude --help accounts

Same tools, either account

同一套工具，換帳號就好

Sign in with a Claude account, a ChatGPT account (browser OAuth or device code over SSH), or an API key. Tools, UI and slash commands stay the same. The ChatGPT path adds a Codex-style apply_patch (shown as Patch), Codex Apps from your ChatGPT connections, and the /daybreak cyber access tier.

用 Claude 帳號、ChatGPT 帳號（瀏覽器 OAuth，或 SSH 上用 device code）或 API key 登入都行，工具、介面、斜線指令完全一樣。走 ChatGPT 時還多了 Codex 式 apply_patch（畫面上顯示為 Patch）、ChatGPT 裡已連好的 Codex Apps，以及 /daybreak 網路安全存取檔位。

$ claude /goal all tests pass

Keep going until it is done

做到才算完

Give a finish condition. At the end of every turn a separate model call reads the transcript and decides whether it holds; if not, Claude is told what is missing and continues. It stops after 9 misses in a row so it cannot loop forever.

給一個完成條件。每輪結束時另一次模型呼叫讀對話紀錄判斷是否達成，沒達成就告訴 Claude 還差什麼、繼續做；連續 9 次沒達成會強制停下，不會無限循環。

常駐的團隊

$ claude Tmux

A terminal Claude can drive

Claude 能操作的終端

The Tmux tool gives Claude a persistent interactive terminal: start a REPL, send keys, press Ctrl+C, read the screen. It runs on its own socket, isolated from your tmux server, and inside the Bash sandbox when that is on.

Tmux 工具給 Claude 一個可持續互動的終端：開 REPL、送按鍵、按 Ctrl+C、讀畫面。它用自己的 socket，與你的 tmux 隔離；開了 Bash 沙箱時也在沙箱裡跑。

$ claude --plugin-dir ./blast-radius

Mods change the harness itself

Mods 改造工具本身

A Mod is one JS/TS file that can register commands, hold or rewrite tool calls and draw UI in the terminal and in claude web. The Blast Radius example holds risky commands and shows what they would delete before you choose Proceed or Cancel.

Mod 是一個 JS/TS 檔，能註冊指令、暫停或改寫工具呼叫，在終端和 claude web 畫介面。Blast Radius 範例會先攔住危險指令，列出會刪掉什麼，再讓你選 Proceed 或 Cancel。

What the fork adds

這個分支多了什麼

  • claude webClaude Code in your browser: rendered math, Mermaid and diffs, PDF and Office previews, comments on files, interject or stop mid-turn.在瀏覽器裡用 Claude Code：公式、Mermaid、diff 直接渲染，預覽 PDF 與 Office，在檔案上留言，回合中途插話或立刻停止。

  • ModsOne JS/TS file adds commands, rewrites tool calls, and draws bands and side panels in the terminal and the web UI.一個 JS/TS 檔就能加指令、改寫工具呼叫，在終端與網頁介面畫狀態條和側邊面板。

$ claude web --no-open

A browser UI that stays on your machine

瀏覽器介面，資料留在本機

The web UI talks to your local claude. It listens on localhost only; the one-time token in the URL becomes a cookie and leaves the address bar. LAN access needs an explicit --dangerously-allow-local-network.

網頁介面連的是你本機的 claude，只監聽 localhost；網址裡的一次性 token 換成 cookie 後就從網址列移除。要讓區網存取必須明確加上 --dangerously-allow-local-network。

$ claude web # local only, opens the browser $ claude web --no-open # over SSH: print the URL only

Simulated session with the real UI labels: read, edit with a diff, approve a command, check the result.用真實介面文字模擬的一次會話：讀檔、改檔看 diff、批准命令、看結果。

$ claude --plugin-dir ./hello-mod

Change the harness, not your habits

改造工具本身，不必改習慣

A Mod is a plugin with a hooks module. It can register slash commands, intercept tool calls, and render UI that shows in both the terminal and claude web. The repo ships examples: Token Weather draws a context-usage band; Blast Radius shows what a risky command would touch before it runs.

Mod 就是帶 hooks 模組的插件：註冊斜線指令、攔截工具呼叫、畫出同時出現在終端與 claude web 的介面。repo 內附範例：Token Weather 在輸入框上方畫上下文用量條，Blast Radius 在危險指令執行前列出它會影響什麼。

hello-mod/ ├── .claude-plugin/plugin.json └── hooks/ ├── hooks.json { "modules": ["./register.ts"] } └── register.ts registers /hello and a tool interceptor $ claude plugin validate ./hello-mod # static scan, runs no code $ claude plugin test ./hello-mod
