`/app/doomgeneric_mips` is a MIPS ELF build of doomgeneric; its source is in `/app/doomgeneric/`. Write a MIPS emulator in JavaScript, `/app/mipsvm.js`, including the system calls the program needs, so that `node mipsvm.js` (run from /app) executes that binary, lets it read and write files, and saves each rendered frame as it is produced. Passing means DOOM boots and the first frame it writes is correct.
