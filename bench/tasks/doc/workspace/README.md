tomlfmt  - formats toml files.  install it with pip install tomlfmt. usage tomlfmt file.toml  or tomlfmt --check file.toml (exit code 1 if not formatted) or tomlfmt --write dir/ .  options: --indent N (default 2), --sort-keys, --line-width N (default 88). config can go in pyproject.toml under [tool.tomlfmt] with the same keys (indent = 4 etc).
